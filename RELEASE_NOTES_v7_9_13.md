# Nowak Workshop OS v7.9.13

- Scheduled repairs now display Today, Tomorrow, or the saved calendar date directly in the repair card.
- Existing repair schedules can be rescheduled from the same control.
- Purchase-order supplier choices now include Lea Hung, Rech, Mega Music and Drum Factory Direct.
- Add New Supplier allows a supplier name and optional email address to be saved on the device.
- Custom suppliers can be selected for a whole target order or an individual drum row.
- Suggested shortages and purchase-order panels are generated dynamically for every selected supplier.
- Lea Hung remains the default supplier.
