# Nowak Workshop OS v7.9.18

- Brass and Black Nickel tension rods no longer use Stainless Steel descriptions.
- Brass and Black Nickel tom/snare rods use supplier code TR01 and size 52mm.
- Brass and Black Nickel bass-drum rods use supplier code TR01 and size 115mm.
- Chrome hardware continues to use Stainless Steel tension rods with the existing Chrome sizes and codes.
- Reorder Planner, inventory allocation, shortage calculations and purchase-order formatting use the corrected finish, code and size.

- Corrected the Brass/Black Nickel bass lug gasket purchase-order line.
