# Nowak Workshop OS v5.2

Nowak website price-guide auto pricing.

## Nowak block-stave snare drums
Prices auto-populate from the published Nowak Drums website price guide when:
- Ownership = Nowak
- Construction = Stave
- Drum Type = Snare
- Timber and size match a published price

Published timber tiers included:
- Standard: Blackbutt, Jarrah, Marri
- Premium: Sheoak, Wandoo
- Fiddleback: any timber name containing Fiddleback

Published sizes included:
- 12 x 7
- 13 x 7
- 14 x 5
- 14 x 5.5
- 14 x 6
- 14 x 6.5
- 14 x 7
- 14 x 8

Finish handling:
- Natural = published base price
- Satin = published base price
- High Gloss = published base price + $100
- To Be Decided = $0 for a matched website configuration

Brady snare-shell pricing remains:
- Stave Satin $600
- Stave High Gloss $650
- Ply Satin $400
- Ply High Gloss $450

Configurations not listed on the website continue to use the existing Workshop OS fallback pricing rule.

No Supabase migration required.
