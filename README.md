# Nowak Workshop OS v5.4.0 — Launch Pack

This release adds marketing features without changing the existing workshop workflow.

## Nowak drums only
Launch Pack appears only on Nowak Job Cards. Brady and Unallocated builds remain internal-only.

## Four media checkpoints
- Timber: 1–3 photos
- Machined shell: 2–4 photos
- Finish reveal: video or photos
- Completed drum: approximately 8–10 photos

## Generated drafts
After all four checkpoints contain media, Generate Launch Pack creates:
- Facebook draft
- Instagram draft
- Website description draft
- Customer email draft for Custom orders

Nothing is published automatically.

## Marketing tab
Draft folders:
- Draft
- Ready
- Published
- Archived

Drafts can be edited, approved, copied, marked published or archived.

## Rollback
v5.3.5 remains the stable rollback version. Re-deploy it at any time if required. The extra v5.4 database table does not affect v5.3.5.

## Supabase
Run `supabase/v5_4_launch_pack.sql` once before deploying v5.4.0.
