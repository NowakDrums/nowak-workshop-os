# Nowak Workshop OS Web App v2.0

Major upgrade:
- Single v2.0 Supabase migration
- Drum type workflow: Snare, Tom, Floor Tom, Bass Drum
- Nowak / Brady build tracking
- CB number
- Customer name, email, shipping address and due date
- Price rule framework: Nowak Stock, Nowak Custom, Brady Wholesale, Brady Custom
- Wholesale price, custom price, shipping, total price
- Timber story field
- Shell thickness, re-ring size, construction notes
- Stave Triton saw and stave-size calculator
- Ply veneer calculator with 12/13/14 inch sizing
- Communication Centre with Kelly & Kyle email sign-off
- Facebook and Instagram draft generator

Important:
1. Run `supabase/v2_0_migration.sql` in Supabase SQL Editor.
2. Upload the app files to GitHub.
3. Vercel will redeploy automatically.
