# Nowak Workshop OS v6.8.1

## Archived drum serial details

Archived drum cards now clearly display:

- Production number
- Nowak serial number for Nowak drums
- CB number for Brady / CB drums

The Nowak serial field shows `Not entered` when a serial number has not yet been recorded, making missing information easy to identify without hiding the field.
