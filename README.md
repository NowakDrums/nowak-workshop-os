# Nowak Workshop OS Web App v1

This is the proper web-app version designed for deployment to Vercel.

## What is included

- React/Vite web app
- Supabase database connection
- Dashboard
- Workshop Today batch planner
- Individual drum progress buttons
- Production board
- iPhone-friendly layout
- PWA manifest

## Tomorrow's setup steps

1. Create a GitHub repository.
2. Upload this folder.
3. Connect it to Vercel.
4. Add these Vercel Environment Variables:
   - VITE_SUPABASE_URL
   - VITE_SUPABASE_ANON_KEY
5. Deploy.
6. Open the Vercel URL on iPhone.
7. Share → Add to Home Screen.

Your Supabase database has already been created and seeded.
