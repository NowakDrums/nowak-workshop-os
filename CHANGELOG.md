# Nowak Workshop OS v7.9.51

Vercel deployment repair only.

- No Workshop OS feature, data, Supabase, Shopify mapping, inventory, pricing, production, media, purchase-order or customer workflow changes.
- Pins the Vercel/Node runtime target to Node.js 22.x.
- Pins dependency installation to npm 10.8.1 to avoid the npm 10.8.2+ `Exit handler never called!` installer failure seen in the Vercel build logs.
- Adds a Vercel install-command override:
  `npx npm@10.8.1 install --no-audit --no-fund`
- Keeps Vite explicitly installed in the existing dependencies so `npm run build` can resolve `vite build` after a successful install.
- This patch intentionally does not include a hand-authored package-lock.json. A lockfile should only be committed after it has been generated by a successful package-manager run, rather than guessed or fabricated.
- After this deploy succeeds, a generated package-lock.json can be added in a follow-up housekeeping patch.
