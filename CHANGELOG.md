# Nowak Workshop OS v7.9.50

Customer thank-you text addition only.

- Keeps the existing Send Thank You Email button.
- Adds Send Thank You Text beside it on completed/sold/shipped/archived Nowak drum Job Cards.
- Uses the customer's saved mobile number and first name.
- Copies the approved plain-text thank-you message, including the direct Google review link, to the clipboard.
- Opens the device messaging app addressed to the customer. Paste the copied message and send.
- If clipboard access is blocked, the message is displayed so it can be copied manually.
- If no mobile number is saved, Workshop OS asks for one first.
- Brady/CB production is unchanged.
- No Supabase, pricing, inventory, hardware, production, purchase-order or photo changes.
